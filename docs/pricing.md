# Pricing & Availability

## Current Status

As of **April 25, 2026**, RFM Architecture operates as a single MIT-licensed open-source product.

## Plans

There is currently one operational offering:

- **Open Source (MIT)** — includes all features that are actively available in this repository.

There are currently **no paid tiers** (no Pro, Team, or Enterprise plans).

## Temporary Feature Removal

The previously planned premium feature set has been **temporarily removed** from active availability while it is being reworked.

To match current operational behavior:

- Do not expect premium-only entitlements or billing flows.
- Do not expect subscription management in the current application experience.
- Assume all currently shipped functionality is covered by the open-source offering.

## Future Changes

If/when paid plans return, this page will be updated first with effective dates and an exact feature matrix.
